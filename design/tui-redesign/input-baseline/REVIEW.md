# 输入标记、状态基线与快捷键

2026-09-11。本轮明确不改变焦点设计。

输入框和用户消息左侧采用一格实心背景标记，不依赖竖线字形。输入框沿用原有聚焦/失焦判定和配色，窄屏同样保留标记。模型状态从输入灰色区域移到框外的单行基线；同一行右侧是换行、命令和发送提示，窄屏优先保留模型与发送。文本编辑高度保持不变。

Ctrl+C 在输入框拥有焦点且没有弹层时清空当前编辑缓冲；使用编辑 checkpoint 和 revision，可以 Ctrl+Z 撤销。普通草稿与问题回答互相隔离，问题绑定不被清空。空输入不退出也不停止工作。Ctrl+D 沿用保存草稿后退出路径，Ctrl+Q 保留兼容。

Shift+Enter 主提示，Alt+Enter 兼容。Unix/WSL 请求 CSI-u 键盘增强，原生 Windows 保留修饰键事件路径。增强协议退出时弹栈，并用共享标记避免 panic hook/Drop 重复弹栈。不支持该协议的终端仍需要 Alt+Enter，未声称所有宿主均可区分 Shift+Enter。

验证：全目标 164 通过、3 个既有性能测试忽略；另新增问题缓冲清空/撤销隔离测试 1 通过，总计 165。最后窄屏标记调整经四项 Composer 专项复验，Clippy、格式、diff 检查和 binary 构建通过。真实 PTY 输入 discard + Ctrl+C + first + CSI-u Shift+Enter + second + Ctrl+D；退出后通过 App 读取到准确的 first\nsecond 草稿，未产生提交输入，键盘增强只弹栈一次。
