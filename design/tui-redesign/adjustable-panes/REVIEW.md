# 连续栏界、加粗文字与鼠标调宽

2026-09-11。

左右栏界使用单列 #282828 背景，不依赖字形。默认文字应用终端 BOLD 属性，菜单清屏后也恢复此字重；具体字形与粗体表现仍取决于宿主终端。输入正文保持默认两行。

左右边界为真实鼠标拖动入口，拖动时橙色，松开结束。每侧最少 24 列，中栏至少 56 列。指针经过输入和正文时保持拖动捕获，Esc/窗口 resize/收到 FocusLost 事件可结束拖动。窗口缩小仅临时约束显示宽度；主动拖动后记住新布局。偏好存在 UI 内存里，切会话保留，重启恢复默认。不读写终端配置。

同一个布局驱动鼠标命中、正文换行、输入宽度、详情排版与边界绘制。修复窗口约束后拖动一侧时另一侧的偏好宽度意外恢复而跳动的问题。

全目标测试 161 通过、3 个既有性能测试忽略，Clippy 通过。最后一项另一侧固定边界的调整经过 3 个拖动专项测试复验；二进制重新构建。图为生产渲染器的合成示例，不是原生终端截图；resized 示例左 44 列、右 32 列。测试通过真实 MouseEvent → reducer → renderer 路径验证拖动，两项图只展示渲染结果。
