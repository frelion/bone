# 组件尺寸与层级

2026-09-11。用户反馈：需要更漂亮，组件显小、界面像 demo；问题并不限于某个终端。延续明确边界、参考 OpenCode 观感的方向。

本轮修改实际 Ratatui 布局：
- 高度至少 24 行时，会话条目增加上下各一行内边距，普通条目三行高，条目间一行不可点击空隙。新建会话使用三行高按钮，与列表左右边缘对齐。
- 保留纵向栏界，标题下增加横向分隔，对话从第五行开始。
- 输入正文默认至少两行（按后续反馈减少一行），与模型行、提示行一起形成至少六行的 Composer；聚焦时显示橙色左边线。编辑、标题和用户/Agent 正文统一内缩。
- 命令、模型和接入菜单增加行距，标题加粗并增加留白；字段标签与输入间距扩大。
- 高度不足 24 行恢复紧凑尺寸。40×12 保留至少三行历史。未修改终端字号。

验证：全目标测试 158 通过、3 个既有性能测试忽略；clippy -D warnings、格式、diff 检查和 binary 构建通过。新增点击几何测试覆盖 12/23/24/40 行，确认扩大条目的内边距可点击、条目间隙不打开会话。顺手修复既有 PTY 测试中 openpty 的多余可变引用，再次运行四项真实 PTY 测试通过。

预览：index.html 默认 1:1 显示，可切换前后、菜单和窄屏。SVG 来自生产渲染器的合成状态，PNG 来自本机浏览器；原生终端字体、字号与字形接缝未通过这些预览验证。示例增加公开 UI action 驱动的菜单场景，未为预览开放内部状态。字体回退与粗体导出已修正。
