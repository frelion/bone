# Platform runtime previews

These SVGs are generated by the current production renderer through the
crate-private, ignored `tests::preview::render_preview_artifact` test. They are cell-grid evidence for layout,
surface, typography roles, continuous dividers, and preferred pane widths.
They are not native-terminal font or anti-aliasing certification.

```sh
BONE_TUI_PREVIEW_WIDTH=160 BONE_TUI_PREVIEW_HEIGHT=40 \
  BONE_TUI_PREVIEW_SCENARIO=conversation \
  BONE_TUI_PREVIEW_OUTPUT=design/tui-redesign/platform-runtime/conversation.svg \
  cargo test -q -p bone-tui --lib --locked \
  tests::preview::render_preview_artifact -- --ignored --exact
BONE_TUI_PREVIEW_WIDTH=160 BONE_TUI_PREVIEW_HEIGHT=40 \
  BONE_TUI_PREVIEW_SCENARIO=resized \
  BONE_TUI_PREVIEW_OUTPUT=design/tui-redesign/platform-runtime/resized.svg \
  cargo test -q -p bone-tui --lib --locked \
  tests::preview::render_preview_artifact -- --ignored --exact
```

The resized fixture records a left width of 44 cells and right width of 32.
