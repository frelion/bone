# Platform runtime previews

These SVGs are generated by the current production `bone_tui::view::render`
path through the `preview` example. They are cell-grid evidence for layout,
surface, typography roles, continuous dividers, and preferred pane widths.
They are not native-terminal font or anti-aliasing certification.

```sh
cargo run -q -p bone-tui --example preview -- 160 40 conversation \
  > design/tui-redesign/platform-runtime/conversation.svg
cargo run -q -p bone-tui --example preview -- 160 40 resized \
  > design/tui-redesign/platform-runtime/resized.svg
```

The resized fixture records a left width of 44 cells and right width of 32.
