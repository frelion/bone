# BONE TUI：设计实验室

2026-10-02 · 基于 `7d45efb`（0.6.0） · 分支 `codex/tui-design-lab`

## 本轮工作简报

用户要改善长时间软件工程协作的设计细节：人在读什么、Agent正在做什么、插话何时生效、失败后怎么继续。已有 Ratatui、slash、实时工具、历史搜索；这次的假设是**操作与信息组织没有形成稳定契约**。本轮先研究、提出对立方向、做反例，再生成可浏览原型。

约束：普通对话；一个 Agent；Job 是不可要求用户调度的内部单元；任何思考仍在 Job 内。读旧内容不能挡住新指令，折叠不能伪造结论，UI不能用状态文案替代版本检查、停止、未知写保护。默认场景 80×24 与 120×40。

## 随机字符串方法

三个 GPT-6.1-Sol 分别承担操作批评、跨领域研究、盲发散。各自先写三个未接受随机刺激的假设；盲发散者在初稿前不看 BONE 现有界面和另外两份报告。主代理用 Python `secrets.token_hex(12)` 生成 24 位字符串。生成后保存在 [random-seeds.json](random-seeds.json)，不重抽喜欢的结果。

固定词表（索引从零）：潮汐、机场转机、铅字排版、舞台后台、厨房出餐、信号灯、乐谱、镜头剪辑、绳结、地图图例、地铁换乘、缝纫、潮线、棋谱、黑匣子、书页批注、航海日志、电梯、显微镜、乐队排练、速记、门槛、呼吸、旋钮。

字符串偏移 `0 / 8 / 16` 处各取两个十六进制字符，转为整数后 `% 24` 映射词。每词强迫生成三项改变操作/时序/信息层级的机制，共 27 项；每人至少否定两项自己的方案。词只作刺激，不当产品文案，也不能替代已有约束。字节取模并非完全均匀分布；此处目的为打散联想，不用于抽样统计。

然后交换反例。独立生成只减少互相模仿，不能证明代理观点是用户调研；随机法也没有被本轮证明比普通构思更有效。

## 统一情景

修复 token 过期后 `/me` 仍返回 200。Agent 读取鉴权路径、跑 20 秒测试；用户中途说“只解释先别写”；输入先被保存，后由 Agent 纳入，新动作在执行器的版本保护下继续。先前启动的检查返回编译失败；用户阅读错误、回答“返回 401；现在可以改代码，并补过期测试”；Agent 继续并交付。另设未知写入核查反例。`cargo test` 会写构建产物、可执行带副作用的脚本，不能称为只读；原型不以工具名承诺已启动动作零写入。

所有设计方向使用同一组输入、结果和时间。原型中的事件为合成样例；没有执行模型或工具。当前代码缺陷的 PTY/源码证据由 [critique.md](critique.md) 单独记录，不能用原型证明运行可靠。

## 阅读

- `index.html`：比较界面、同情景状态、窄/宽屏、证据阅读、命令发现。
- [critique.md](critique.md)：可复现缺陷、随机机制、操作层级方向。
- `research.md`：原始资料、可转移原则、反例。
- `divergence.md`：四种独立操作模型与字符布局。
- `decision.md`：第二轮交叉批评、去留、推荐方案和落地边界。

尚未实施生产 TUI 改版。本轮产物用于让设计选择具体可见，不把合成屏幕称为验收。
