# BONE 0.10.1

## 生成未完成时继续推进

- 模型以原生 `Length` 结束时，整轮提案只留审计，不执行工具，也不交付半截回复。Job 保留原任务和已经完成的动作，允许一次重新规划为更小的完整动作。
- 恢复机会从持久事件计算；停止、重启和恢复不会重置。连续受限会明确暂停，正常工作回复被接受后才重新计算工作机会。所有调用继续消耗原输入的共享额度。
- 过滤、明确的上下文限制、未知结束原因和调用错误分别报告。沿用 Rig 的原生结果合同，成功但缺少结束原因时接受非空结果。
- TUI 自动调整期间显示“本轮生成未完成，正在继续”；最终暂停说明具体原因，已经完成的进度保留。

## 分步写入与摘要

- `write_file` 必填 `mode = replace | append`。追加必须提供上一成功版本的 SHA，核验源版本后原子替换，返回完整文件的新 SHA 与大小。普通局部修改继续使用 `edit_file`。
- 分步写入允许保留中间文件；权限、工作区写锁、冲突检查和 16 MiB 文件总大小限制继续有效。不拼接半截工具参数。
- 摘要沿用 Profile 的原生生成配置，删除隐藏的 2048 截顶。受限摘要最多重试一个不超过原材料一半的完整前缀；只有使后续工作请求实际缩小的完整摘要才能提交。失败时原文和旧摘要保留。

## 诊断与验证范围

调用记录区分传给 Rig 的生成配置、服务端报告的用量和结束原因、安全原生观察；缺失值保持未知，不记录认证信息或完整 HTTP 请求。模型结果与对应状态在同一 SQLite 事务提交。

本地验收通过 290 项 Rust 检查、8 项 Python 检查和 32 项 TUI PTY 场景。原生 Rig 协议故障测试覆盖合法 JSON、半截参数和纯思考输出受限时零执行、有限恢复、取消与重启、摘要保留和追加冲突。固定协议对照中新版本 3/3 完成分步文件任务，0.10.0 基线 0/3；真实 `gpt-6-luna` 订阅完成跨 CLI 重启的两轮工程修改。

证据和边界见 [生成续做验收](https://github.com/frelion/bone/blob/v0.10.1/docs/results/2026-10-08-generation-continuation/README.md)。真实订阅任务没有触发截断；受限恢复由原生协议测试覆盖。用户另一台机器的 New API 故障没有原始响应，具体触发原因仍未知。不自动提高用户生成额度、不自动换模型或改变协议。

发布包覆盖 macOS、Windows、Linux，各提供 x64 和 ARM64。系统基线为 macOS 15+、Windows 11 / Server 2025+；Linux 提供 musl 静态包。每个目标经过原生测试、构建和解压后二进制启动检查；校验信息随包提供为 `SHA256SUMS` 与 `release-builds.json`。
