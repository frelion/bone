# BONE 0.9.4

One conversational Agent with persistent internal Jobs, a native Rust TUI, and Rig model connections.

## What's included

- A rebuilt single-package core: durable Jobs, multi-turn context, interruption, recovery, and protected unknown writes.
- A Ratatui workspace with session history, Markdown, live model and tool progress, retained drafts, and explicit question replies.
- `/connect` for saved API connections or ChatGPT subscription login; `/model` accepts the provider's native model name. Existing local Codex login can be reused.
- Two-line session entries with a name, actual state, local activity time, and distinct current/selection indicators. `/new` opens the composer; empty sessions do not occupy the sidebar.
- Native Windows shell execution, process-tree cancellation, atomic file replacement, private credential files, editor, and clipboard support.

Each archive contains the executable, `INSTALL.txt`, README, and MIT license. `SHA256SUMS` covers the release files; `release-builds.json` records the exact source commit, target, toolchain, and archive hash.

macOS builds target macOS 15 or newer. Windows builds are tested on Windows Server 2025 (x64) and Windows 11 (ARM64); use an interactive terminal, preferably Windows Terminal. Linux binaries use static musl and do not require glibc. Optional Bedrock, Vertex AI, and Candle integrations are source-build features, not included in these standard binaries. Keyboard handling depends on the terminal.

## Install

Extract the archive for your platform. On macOS/Linux:

```sh
mkdir -p ~/.local/bin
install -m 755 bone ~/.local/bin/bone
bone --version
bone
```

Add `~/.local/bin` to your PATH if needed. On Windows, run `./bone.exe` in PowerShell or copy `bone.exe` into a directory on your user PATH.

Start with `/connect` to choose your model connection; `/new` begins another conversation. Git is needed for Git diff features. Model use requires a supported provider's credentials or a compatible ChatGPT subscription.

Windows shell commands use `cmd.exe`. Use a local drive or map a network workspace to a drive letter; shell execution refuses UNC working directories because `cmd.exe` would otherwise switch to the Windows directory. Clipboard copying preserves Unicode text and uses Windows CRLF line endings.

## Compatibility and verification

The rebuilt core uses `~/.bone/v2` (under USERPROFILE on Windows) and does not migrate the old 0.4.x runtime state. Existing 0.9.x state remains in that directory. Use a private user directory for data and credentials.

All six native runners must pass the Rust unit/integration suite and both original and extracted-binary CLI smoke checks before this release is published. These checks use local protocol fixtures; they do not certify every provider or personal login. The archives are not code-signed or notarized.
