# BONE 0.10.0

## 行为变化

- 移除 `/reconcile`、`bone reconcile` 和会话级“需核查”门禁。中断进入普通工具结果，Agent 检查实际状态后决定下一步。
- 停止会收集已经启动的工具结果与部分输出，不自动重放。重启后缺失结果只补一次中断事实。
- 会话切换、`/new`、换模型和外部编辑草稿不停止后台工作。换模型影响后续请求；其他已打开会话保留各自连接。
- 当前回复完成后，旧用户输入不会自动重跑；仍可通过普通新消息或显式恢复续做。明确放弃旧方案时，内部 Agent 可结算其未完成委派，无需先让失败的子工作成功。

## 当前数据格式

会话直接保存到数据目录的 `sessions.sqlite`，旧会话不迁移。当前快照要求必需字段完整，拒绝未知字段；SQLite 只创建当前完整 schema，不检测或补旧列，不回填旧事件。保存的连接配置继续使用当前配置接口。

工作区和认证源各使用一把稳定物理锁，不保留旧锁或 pending 标记接线。公开 TUI slash 只有 `/new /model /connect /help /quit`。

Rust API 删除 `UnknownWrite`、`SessionState.unknown_writes` 和 `Engine::resolve_write`。保留 `post / step / stop / resume`；新增 `profile_recipe` 只读当前连接配置。

工作区物理写锁、输入 revision、SQLite 原子提交和 Rig 原生调用/结果身份继续有效。停止不等于撤销已经发生的效果。
