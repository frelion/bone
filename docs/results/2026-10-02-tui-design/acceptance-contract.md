# 方向 A 独立 PTY 验收合同

本文件先定义可观察合同，运行结果另记。真实 PTY 使用 `tests/tui_pty.py` 原有 loopback Responses fixture、合成 key、临时 workspace/data。没有真实模型调用、个人凭据读取或 production 工作区写入。目标终端为 80×24、120×40。

| 风险 | 可观察合同 |
| --- | --- |
| 失败冒充就绪 | fixture 返回 HTTP 错误后，退出前状态显示失败及恢复入口；不能只留下“就绪”。 |
| 选区拦截停止 | 真实 shell 未退出时，在输入框 Shift+方向键选区，Ctrl+C 后 SQLite paused=true；原草稿保留、shell 终止、未知写保留。复制走 Ctrl+Y。 |
| 核查破坏编辑状态 | 带有多行草稿及中间光标，从界面进入核查与原文，再逐层 Esc；草稿、光标插入位置、回复目标保持。核查不自动恢复，不重发工具。 |
| 问题隐式抢目标 | 单个或多个新问题到达时独立草稿仍按新指令发送；通过显式问题入口选定后 reply_to 才指向该问题；Esc 只关闭层级，`/message` 显式取消真实路由。 |
| 层级返回跳读点 | 对话 → 运行证据 → 原文，Esc 先返回证据，再返回原对话；继续复制/选择能验证原读点，而非仅看到相似文字。 |
| 证据泄漏未来结果 | shell 运行中证据有真实 start/live 输出，无尚未持久化的完成/最终结果；完成后才出现最终记录。 |
| 新事件与 resize 打断阅读 | 在旧消息阅读时新事件到达，旧消息仍在视口；resize 后仍保留同一条记录；提供未读数量/返回最新入口。 |
| 工具失败被折叠 | 失败 shell 的关键 stderr 和退出码无需先开原文即可看见；成功工具默认只占一行状态摘要。 |
| 长交付难抵达 | 长答案有明确展开/原文入口，通过一次明确操作可读取或复制尾部；原文完整。 |
| slash 选择产生行动 | `/` 出现候选；Enter/Tab 选择仅插入草稿，调用数和事件数不变；第二次明确 Enter 执行完整命令。 |

方向 A 的动作合同：F6 切换输入/对话；Tab 用于补全与编辑；Ctrl+C 始终暂停，Ctrl+Y 复制。`d` 先打开完整可读结果，结果层 `D` 或 `/audit` 才打开审计原文。`/delivery` 直达已有最近交付。核查用独立表单，Esc 取消保留原编辑器快照；记录核查后仍暂停。

所有布局帧在进程退出前采集。终端恢复和退出后的恢复命令独立断言，不能将退出后的 stderr 与 alternate-screen 内容叠成产品布局。只报告实际运行的终端尺寸和场景；不把 fixture 响应验证当作真实模型体验或人工可用性结论。
