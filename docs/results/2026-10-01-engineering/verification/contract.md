# Frozen history pagination contract

Preserve bone::history and history without pagination flags, including legacy JSON array. Add public Rust history pagination API and CLI --limit N / --after EVENT_ID. Either flag activates pagination. Default limit 100; valid 1..1000. Cursor is exclusive, scoped to session, and order is persisted append sequence, never ID or timestamp. JSON page is {events, next_cursor, has_more}; nonempty next_cursor equals last returned event ID even on final page; empty cursor null. has_more reports an additional row at read time. Original Event contents, including summarized source records, are returned. Unknown session, nonexistent cursor and cross-session cursor fail. New appends are available on continuation. No full-session payload materialization in paginated path. Lookahead need not parse the out-of-page payload. Text output preserves event lines and exposes cursor / further-record status. Audit works without config or model calls. Add offline regression tests and user documentation.

Independent verifier fixtures use valid detached SessionState snapshots with no work or jobs, immutable audit events at revision zero, and the existing SQLite schema. A separate intentionally damaged payload tests selective reading only; it is not used to claim normal runtime validity. Public API signature can vary reasonably and is tested with an external caller after implementation. Runtime / authentication changes are unnecessary.
