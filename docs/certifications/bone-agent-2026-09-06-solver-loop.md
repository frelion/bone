## 实际验证的行为

| 场景 | 证据 |
| --- | --- |
| 主力直接用工具 | 真实主力在 4.87 秒请求并完成 `read`，10.34 秒交付文件中的本轮随机值；两次 Work、一次工具、零协调。随机值不在用户提示中。 |
| 长推理时两次问进度 | 2.72 秒和 6.29 秒回复，两次均为 `Keep`，原 Work JobId 不变；两次回复时，原主力提供方请求均尚未返回。 |
| 问进度同时改方向 | 原始输入同时包含状态询问和“不要 A、考虑 B”，真实协调返回 `Reconsider`，原话直接转交下一次 Work。 |
| 旧结果早于协调结论 | A 在 10.69 秒返回后进入暂存；同刻协调结论到达，旧提案被撤销，A 的答案没有发布。 |
| 主力直接交付 | 新 Work 在该会话 18.46 秒发布 `Selected: B`，没有协调重新生成答案。 |
| Stop 与旧回调 | 两个本地模型请求在途时停止，回执立即完成；取消回调不能发旧回复或恢复工作。 |
| 停止后继续对话 | 新输入要求只回复 `WELCOME`，3.94 秒得到回复，旧任务未恢复。 |

时间在每个测试会话中分别从零计起。
测试只延迟第一次 Work 和指定一次 Review 的结果交付，以稳定覆盖先后顺序；
每次调用及其结果均来自真实模型，既不伪造决定，也不编辑答案。
日志单独记录提供方是否已经返回，区别真实请求未完成和单纯延迟交付。
本地取消不证明远端服务已经停止计算。

## 离线与交叉审查

| 范围 | 验证 |
| --- | --- |
| 同步 Kernel | 39 项行为测试，包含固定批次、完整提案检查、依据过时、Pause 来源边界、读清理与未知写入。 |
| Runtime | 21 项行为测试，包含非合作模型取消、写入拒绝取消、真实结果保留、独立截止、幂等关闭和观察流。 |
| 独立交错检查 | 一项测试枚举 96 组成功／失败／取消／超时回调与 Review、工具结果、Stop 的交错；旧提案不得执行写入、发布答案或恢复工作。 |
| CLI 与适配器 | 24 项测试，包含十轮工具零协调、主力纯推理、角色越权拒绝、小上下文投影、同客户端并发及多会话隔离。 |
| 其他工作区模块 | 配置、模型协议和原生工具回归全部通过。 |

实现由内核、执行器和适配器三个职责分别完成，随后交叉审查；另做一次独立只读终审。
本轮确实发现并修复了以下问题：

- 主力的澄清回复原本排在 `Paused` 后，CLI 会提前结束；现先发回复，再发暂停，`Pause + Finish` 只发完成。
- 对已结束且结果未知的写入请求取消，原本会静默接受；现返回明确原因，保留未知事实。
- 已返回 `Unknown` 的写入缺少后续事实入口；现提供宿主 `resolve_write`，经同一个 `JobFinished` 更新原作业。非法或冲突确认被拒绝，相同确认幂等，Stop 后确认不恢复工作。
- 真实读取曾因 `Continue` 立即启动而多做一次过时推理；协议明确说明依赖工具结果时选择 `Wait`。最终上述真实读取使用两次 Work 完成。

`resolve_write` 必须来自宿主已取得的外部确证，不自动查询，不接受模型决定作为确证。
实际外部写入没有用于本轮真实服务测试；写入不确定性、取消拒绝和确证入口通过可控工具验收。
本轮仍是单进程、内存状态；没有引入任务树、持久化、并行主力求解或自动无限重试。

## 复现

配置沿用 BONE 的独立登录与系统设置：协调 `gpt-5.6-terra / low`，
主力 `gpt-5.6-sol / medium`，各 120 秒截止。软提醒默认 30 秒，关闭清理默认 5 秒。
模型可用性、延迟和生成行为仍以实际接入服务为准；一次通过不代表统计可靠性。

```sh
cargo run -p bone-agent --example walkthrough
cargo run -p bone-agent --example interleaving
cargo test --workspace --all-features --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
cargo fmt --all -- --check

BONE_CONFIG="$HOME/.config/bone/config.json" \
  cargo test -p bone-agent --test live_agent --locked -- --ignored --nocapture
```

演示使用虚拟时间，不实际等待 30 秒。真实测试使用临时目录与本轮随机文件内容。
首次登录需要交互授权时，不应把设备码写进验收日志。
